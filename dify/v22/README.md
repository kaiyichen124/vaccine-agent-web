# 儿童疫苗推荐助手 v22

本目录包含根据组会意见调整后的 Dify 工作流。

## 文件

- `vaccine_agent_v22_meeting_revision.yml`：可导入 Dify 的工作流 DSL。

## 本次调整

- 开启图片上传入口，并将拍照识别文字放在输入首位。
- 简化病例输入提示，保留结构化输入作为可选项。
- 单页输出近期需接种、需核实或需暂缓的重点疫苗。
- 为需核实和暂缓项目增加检查要求、处理路径与复评条件。
- 输出知识库文件名、位置和原文摘录。
- 提高国家免疫规划程序和国内专家共识的证据优先级。

## 使用

在 Dify 工作室中选择导入 DSL，上传 `vaccine_agent_v22_meeting_revision.yml`，再核对模型与知识库授权。
